# 京都班別学習・班コード共有版

教員と各班が同じURLを開きます。生徒は班専用コードで参加し、自班のプランを閲覧・編集します。教員は教員用コードで全班のプラン、承認、通過記録、行事設定を操作できます。

## Windowsで手元の動作を確認する

zipを展開し、展開先のフォルダーでPowerShellを開きます。Node.jsが必要です。Node.js 24で確認しました。

```powershell
$teacherSecret = Read-Host '教員用コードを入力（12文字以上）' -AsSecureString
$env:TEACHER_CODE = [System.Net.NetworkCredential]::new('', $teacherSecret).Password
node server.cjs
```

ブラウザで http://localhost:8787 を開きます。停止は Ctrl+C です。教員画面でコードを入力し、「班専用コード」を開くと配布用コードが表示されます。生徒画面を別のブラウザやプライベートウィンドウで開くと、別々のログインを試せます。同じブラウザ内のタブはログイン状態を共有します。

## 複数端末から使う

Node.jsを実行できるホスティングに展開し、配布する同じHTTPSのURLで画面とデータを提供してください。ホスティングに設定する項目は次のとおりです。

- 起動コマンドは `node server.cjs`
- `TEACHER_CODE` は教員だけが知る長く推測されにくい値
- `PUBLIC_ORIGIN` は配布するHTTPSのURLのオリジン（例 `https://example.edu`）
- `HOST` はホスティング側で外部接続を受ける場合は `0.0.0.0`、同じマシンのHTTPSプロキシ経由なら既定の `127.0.0.1`
- `PORT` はホスティング指定の値。未指定なら `8787`
- `DATA_FILE` は再起動・再デプロイで保持される保存領域のファイルパス。未指定なら `data/events.json`

サーバーは1インスタンスで実行してください。複数端末からの利用では、ブラウザに配布するURLのHTTPSが必要です。GitHubにソースを置く場合は `data/`、教員コード、班コードをコミットしないでください。GitHub Pages単体では共有版のサーバーを実行できません。

## 保存されるデータ

共有版の起動時は、京都の行事設定と空の班から始まります。試作版のブラウザに保存されたプランや設定は自動移行されません。共有版で入力したプラン、行事設定と通過記録はサーバーに保存されます。撮影画像は撮影した端末に保存され、画像本体はサーバーに送信されません。

班専用コードは、それを知る人を班員として扱う方式です。教員は該当する班だけに配布してください。保存ファイルには班コードとプランが含まれるため、バックアップも非公開で保管してください。
